## ✍️ I learn by building, then I teach it

The clearest way I know to *actually* understand something is to build the thing that explains it. That instinct is most of my best work:

- **[The EVM Book](https://evm-book.vercel.app)** — an interactive, book-length guide to the Ethereum Virtual Machine. 20 chapters, purpose-built visualizers (a live **bytecode disassembler / opcode stepper**, a LIFO **stack machine**, a **gas meter**, a **state-transition** explorer), Mermaid diagrams, full-text search, dark-mode PWA. I built it to learn the EVM end-to-end — then made it teach everyone else.
- **[blog-rs](https://github.com/Bunty9/blog-rs)** — a self-hosted blog engine written in **Rust**: markdown plus interactive shortcodes (charts, animations, embedded code playgrounds). The tool I write *with*, built from scratch.
- **[dev.to/bunty9](https://dev.to/bunty9)** — where the notes turn into articles.
